Slice 1 — first sound

A Rust graph rendering quanta inside an AudioWorklet, driven from this page through a command ring in the worklet's own linear memory. The readout below is not sent here — it is read out of a state block, sixty times a second (ARCHITECTURE.md §3).

Decoded on this page and copied into the worklet's own memory, then named by one command through the ring. The frames never travel as a message: §3 keeps data out of the ring, so what crosses is where they already are. With none loaded there is no clip, and a project with no clip is the silence it is.

Rendered outside real time by the same engine, in blocks of its own choosing — not recorded from what is playing. Two tests compare the two paths sample for sample; this is where you check that by ear.
